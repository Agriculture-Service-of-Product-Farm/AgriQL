Install AgriQL on Linux

This installs the agriql command on a current Linux system. apt install agriql and dnf install agriql will not work. Those packages are not published.

What you need

On Debian or Ubuntu:

sudo apt update
sudo apt install build-essential curl pkg-config git

On Fedora:

sudo dnf install gcc make curl pkgconf-pkg-config git

Then install Rust:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

Build

git clone https://github.com/SbruiceS/AgriQL.git
cd AgriQL
cargo build --release -p agriql-cli
sudo install -m 755 target/release/agriql /usr/local/bin/agriql

Check the installation

agriql version
agriql init
agriql doctor

Configuration is ~/.config/agriql. Data is ~/.local/share/agriql. A database file is created inside the data directory when you create a database.

Next

Create a database and run a query. For a machine that other people connect to, follow the server guide instead of running the command in your own login.

Remove the program

sudo rm /usr/local/bin/agriql

That does not delete ~/.local/share/agriql or your .aqdb files.

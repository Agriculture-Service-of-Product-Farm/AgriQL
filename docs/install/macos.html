Install AgriQL on macOS

This installs the agriql command on the Mac you are using. The build is for that Mac, whether it is Apple silicon or Intel. Homebrew does not carry AgriQL yet.

What you need

  • A current macOS.
  • The Xcode command-line tools.
  • Rust, from rustup.
  • Git, which the command-line tools provide.
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

Build

git clone https://github.com/SbruiceS/AgriQL.git
cd AgriQL
cargo build --release -p agriql-cli
sudo install -m 755 target/release/agriql /usr/local/bin/agriql

If /usr/local/bin is not writable, copy the binary to a directory already on your Path, such as $HOME/.local/bin.

Check the installation

agriql version
agriql init
agriql doctor

Configuration and data are under ~/Library/Application Support/AgriQL.

Next

Create a database and run a query.

Remove the program

sudo rm /usr/local/bin/agriql

That does not delete ~/Library/Application Support/AgriQL or your database files.

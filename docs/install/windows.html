Install AgriQL on Windows

This installs the agriql command on 64-bit Windows 10 or Windows 11. WinGet does not list AgriQL yet. Do not use an identifier that has not been published.

What you need

  • A 64-bit Windows system.
  • Git for Windows.
  • Rust, installed with rustup. Accept the default Visual Studio build tools when rustup asks. AgriQL needs that linker.

Build

Open PowerShell.

git clone https://github.com/SbruiceS/AgriQL.git
cd AgriQL
cargo build --release -p agriql-cli

The program is target\release\agriql.exe.

Put it on PATH

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\AgriQL\bin"
Copy-Item .\target\release\agriql.exe "$env:LOCALAPPDATA\AgriQL\bin\agriql.exe"

Add %LOCALAPPDATA%\AgriQL\bin to your user Path, then open a new PowerShell window.

Check the installation

agriql version
agriql init
agriql doctor

version should report engine 3.10.1. init creates configuration under %APPDATA%\AgriQL and data under %LOCALAPPDATA%\AgriQL.

Next

Create a database and run a query. To serve other machines, use the server guide on a system you administer. A desktop Windows install is for local use.

Remove the program

Delete agriql.exe and the Path entry. That does not delete %LOCALAPPDATA%\AgriQL or your .aqdb files.

Documentation

AgriQL 3.10.1 is the agriculture-native database language from Agricultural Service of Product Farm. These pages tell you how to install it and how to use the current release. They do not describe unfinished work as if it were available.

Install from source. apt, dnf, Homebrew, and WinGet do not yet carry an AgriQL package.

Install

WindowsBuild agriql.exe and put it on PATH. macOSApple silicon or Intel. LinuxDesktop and workstation. ServerA service on a private network.

After installation

Getting startedCreate a database and run a query. ClientsPython, R, and Arrow.

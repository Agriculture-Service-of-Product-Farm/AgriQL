Documentation

These pages describe AgriQL 3.10.1, the agriculture-native database language from Agricultural Service of Product Farm. They do not describe how the software is built.

Install from source. apt, dnf, Homebrew, and WinGet do not yet publish an AgriQL package. Commands for those tools are not listed here, because they would fail.

What this release does not do

AgriQL 3.10.1 is a database language for agricultural measurements. The list below is the boundary of this release. A later release may move it. This page will not pretend that it already has.

Queries

  • A summary reads one table. It does not join two tables.
  • The aggregates are count, minimum, maximum, average, and standard deviation.
  • Each agriql query starts fresh. Name the database in the statement.

Files

  • CSV, TSV, JSON, and Excel can be imported and exported.
  • Parquet is refused.
  • A spreadsheet that exists only at a web address is refused.
  • An import path that leaves the data directory is refused.

Install

  • Windows, macOS, and Linux are installed from source.
  • apt, dnf, Homebrew, and WinGet do not publish an AgriQL package.
  • A server listens on a private network, on port 5471. A web browser cannot open agriql://.

Clients

  • Python, R, and Arrow send a query or convert a text table. They are not a second database.
  • Pandas and Polars are optional. The Python client does not require them.

What the release does do is on Queries and Getting started.

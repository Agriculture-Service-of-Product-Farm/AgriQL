Agricultural Service of Product Farm

The record that knows a measurement from a number.

AgriQL is a database language for soil, crop, water, and weather. A season stays in one .aqdb file. A value keeps its unit. A length is not added to a mass.

Questions

What is AgriQL?

AgriQL is a database language for agricultural measurements, made by Agricultural Service of Product Farm. Version 3.10.1 stores a season in one .aqdb file.

How is AgriQL different from a general-purpose database?

A general-purpose database stores numbers and will add them if you ask. AgriQL rejects a length added to a mass. It does not join several tables in this release, and it is not meant for every application.

Which files can AgriQL import?

CSV, TSV, JSON, and Excel. Parquet is not accepted. A spreadsheet that exists only online is not accepted.

Where can AgriQL be installed?

On Windows, macOS, and Linux, from source. It can also run as a service on a private network. Packages for apt, dnf, Homebrew, and WinGet are not published.

Agricultural Service of Product Farm

AgriQL keeps the measurement honest.

AgriQL is a database language for agricultural records. Soil, crop, water, and weather for one season live in a single .aqdb file. A value keeps its unit. A length is not added to a mass.

01Why it exists A season of readings should not depend on a pile of spreadsheets. 02How it differs What a general-purpose database stores, and what AgriQL refuses. 03What you can ask Import, summarise one table, check it, and write it back out. 04Install Windows, macOS, Linux, and a private server. Version 3.10.1, from source.

The present release

AgriQL 3.10.1 can create a database file, import CSV, TSV, JSON, and Excel, filter and summarise one table, report empty values and unusual numbers, and check a time series for gaps. Python, R, and Arrow can take the rows. They are not a second database.

It does not join several tables. It does not read Parquet, and it does not read a spreadsheet that exists only online. Those are limits of this release, not features.

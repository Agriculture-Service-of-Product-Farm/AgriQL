Agricultural Service of Product Farm

AgriQL

A database for agricultural measurements, and the language used to query them.

Records

A database is one file, ending in .aqdb. It holds the tables for a farm, a trial, or a season: soil readings, crop notes, weather, and other observations.

A value keeps its unit. A length is not added to a mass.

Queries

You ask for the rows you need, or for a summary of one table. Files you already keep as CSV, JSON, or Excel can be imported and written back out.

IMPORT CSV 'soil.csv' INTO agriculture.soil;

SELECT plant_id, AVG(soil_moisture)
FROM agriculture.soil
WHERE soil_moisture < 25
GROUP BY plant_id;

Analysis

Python, R, and Arrow are clients. They send a query to AgriQL and return the rows. They are not separate databases. Spreadsheets and analysis tools stay outside the file.

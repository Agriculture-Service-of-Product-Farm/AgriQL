Install

Choose the system you run.

AgriQL 3.10.1 is built from source. Packages for apt, dnf, Homebrew, and WinGet are not in those public catalogs yet.

WindowsBuild the command and place agriql.exe on PATH. macOSApple silicon and Intel. One command for the machine you have. LinuxDebian, Ubuntu, Fedora, and other current distributions. ServerRun AgriQL as a service on a private network.

Product

Built for the measurement, not for every application.

AgriQL

  • Soil, crop, water, weather, and sensor observations.
  • Incompatible units are rejected.
  • One .aqdb file.
  • CSV, TSV, JSON, and Excel move in and out.
  • Python, R, and Arrow return rows. They are not a second database.

A general-purpose database

  • Any application, not a field or a season.
  • Numbers are stored. The unit check is left to the application.
  • Often a server, or a file with no agricultural meaning.
  • Exchange depends on that product.
  • Analysis tools can drift away from the record.

Limits

What not to expect.

  • A summary query reads one table. It does not join several tables.
  • Parquet, and a spreadsheet that lives only online, are not accepted.
  • The clients do not contain the database.
  • AgriQL is under active development. This site describes version 3.10.1.
